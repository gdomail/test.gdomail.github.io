# GdoMail プライバシーポリシー

本プライバシーポリシーは、Chrome 拡張機能「**GdoMail**」（以下、「本拡張機能」といいます）におけるユーザーデータの取り扱いについて定めるものです。

## 1. 基本方針（開発者によるデータ非収集の原則）

本拡張機能は、**開発者が管理する外部サーバーへユーザーの個人情報やメールデータを送信・収集・保存することを一切行いません。**

本拡張機能は「BYOK（Bring Your Own Key / 自己環境接続型）」のアーキテクチャを採用しており、すべての設定情報およびメールデータは、ユーザー自身のブラウザ内（ローカルストレージ）と、ユーザー自身が構築・管理するバックエンド環境（Google Apps Script ウェブアプリ等）との間でのみ直接処理されます。

---

## 2. 取り扱うデータの種類と利用目的

本拡張機能は、独自ドメインでのメール送信機能を提供するために、以下の情報を取り扱います。

### ① ブラウザ内（`chrome.storage.local`）に保存される情報

ユーザーが拡張機能の設定画面（オプションページ）で入力した以下の情報は、お使いの端末のブラウザ領域にのみ保存されます。

* **バックエンド接続先 URL**（Google Apps Script のウェブアプリ URL 等）
* **認証パスワードのハッシュ値**（入力されたパスワードをブラウザ上で SHA-256 方式により不可逆暗号化した文字列）
* **差出人（From）リスト**（送信元として選択するメールアドレスおよび表示名）
* **添付ファイル上限サイズの設定値**

### ② メール送信時に一時的に処理される情報

ユーザーが Gmail 画面で「独自ドメイン送信」ボタンを押した際、以下の情報がメモリ上で読み取られ、ユーザーが指定したバックエンド URL へ HTTPS（暗号化通信）で直接送信されます。

* **メールの宛先情報**（To / Cc / Bcc）
* **メールの件名および本文**（HTML 形式またはプレーンテキスト形式）
* **添付ファイルデータ**（Base64 エンコードされたファイル内容・ファイル名・MIME タイプ）

※これらのメールデータは送信処理の実行時にのみ使用され、本拡張機能内に履歴として蓄積されることはありません。

---

## 3. 第三者への提供および外部送信について

* **開発者および第三者への提供**: 開発者がユーザーのデータを閲覧、収集、販売、または広告目的等で第三者に提供することは一切ありません。
* **外部通信先**: 本拡張機能は、ユーザーが明示的に設定したエンドポイント URL（`https://mail.google.com` および `https://googleusercontent.com` 配下のユーザー自身の環境）および、ユーザーがバックエンド側で連携設定したメール配信サービス（Mailtrap 等）以外の外部サーバーとは一切通信を行いません。

---

## 4. Chrome ウェブストア ユーザーデータポリシーへの準拠

本拡張機能による情報の利用および転送は、[Chrome ウェブストア デベロッパー プログラム ポリシー](https://chrome.com)（限定使用の要件を含む）に完全に準拠しています。取得したデータは、ユーザーが本拡張機能の主要機能（Gmail からの独自ドメインメール送信）を利用する目的にのみ使用されます。

* [Chrome ウェブストア デベロッパー プログラム ポリシー（日本語案内ページ）](https://transparency.google/intl/ja_ALL/our-policies/product-terms/google-chrome)

## 5. セキュリティ対策

* **パスワードのハッシュ化**: 設定された認証パスワードは平文のまま保存せず、ブラウザの Web Crypto API を用いて SHA-256 ハッシュ値に変換したうえで保持・照合します。
* **通信の暗号化**: すべての外部通信は HTTPS による暗号化通信を使用しています。
* **データの削除**: ユーザーは、拡張機能の設定画面から設定をクリアするか、Chrome から本拡張機能をアンインストールすることで、ブラウザ内に保存されたすべてのデータをいつでも完全に削除できます。
